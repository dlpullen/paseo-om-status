# Paseo OM Status

See how close Pi Observational Memory is to its next compaction from one pill above the composer. Open the pill for observation and reflection progress, counts, and pool sizes. Opening or refreshing the snapshot sends no chat messages and starts no model turns. Pi's existing context meter remains separate.

The plugin reads the selected session's live status through a companion Pi extension and a private local socket. It was verified with Paseo 0.17.4, Pi 1.6.1 or 0.84.2, and Observational Memory 3.1.4 on a Unix daemon. Pi installs OM as a dependency of the companion. A separately installed OM extension should be removed to avoid loading it twice. Sessions without a live bridge show status as unavailable.
